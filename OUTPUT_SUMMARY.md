```

GIO_GCR0_OFFSET = 0x00
GIO_INTDET_OFFSET = 0x08
...
GIO_IRQ_A_ID = 9
```

**What it means**:

- GIO peripheral is at address 0xFFF7BC00
- Register GCR0 is at offset 0x00 from base (so address 0xFFF7BC00)
- Register INTDET is at offset 0x08 (so address 0xFFF7BC08)
- GPIO interrupt group A has ID 9

**Why it's important**:

- Proves the generator used correct hardware values
- Allows you to validate against RM46 datasheet
- Provides audit trail ("this value came from YAML")
