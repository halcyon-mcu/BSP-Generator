int main ( void )

Main application entry point.

Initializes all BSP modules in dependency order:

  1. SYSTEM (dependencies: none)
  2. PCR (dependencies: none)
  3. IOMM (dependencies: none)
  4. PLL (dependencies: SYSTEM)
  5. VIM (dependencies: SYSTEM)
  6. SCI (dependencies: PLL, IOMM)
  7. LIN (dependencies: VIM, PLL, IOMM)
  8. GIO (dependencies: VIM, IOMM)
Returns
Never returns (infinite loop)

void Reset_Handler_C ( void )

C-level reset handler called from assembly startup code.

This function performs the following initialization sequence:

  1. Copies initialized data from flash to RAM (.data section).
  2. Zeros the .bss section in RAM.
  3. Calls system_init() to configure clocks and peripherals.
  4. Calls main().
  5. Enters an infinite loop if main() returns.
Note
This function is called directly from the assembly Reset_Handler after stack pointer initialization.
Warning
Do not call this function directly from user code.
