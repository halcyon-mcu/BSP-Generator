◆ vim_init()

void vim_init ( void )

Initialize the VIM for vectored interrupt mode.

This function:

  • Enables VIM parity checking if supported
  • Initializes all vector table entries to a default handler
  • Does NOT enable any interrupt channels by default
Note
Must be called before registering ISRs or enabling channels
Warning
Does not configure system-level interrupt enable (CPSR I/F bits)

Register an ISR for a specific VIM channel.

Writes the ISR address into the VIM vector table entry corresponding to the given channel.

Parameters
[in]channel_idVIM channel number (valid range: 2..126, excluding reserved channels)
[in]isrPointer to the interrupt service routine
Returns
0 on success, -1 if channel_id is invalid or reserved
Note
Channel 0 is phantom and channel 127 is reserved
This does not enable the channel; call vim_enable_channel() separately
