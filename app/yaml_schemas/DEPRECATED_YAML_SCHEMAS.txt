===============================================================================
CURRENT VALIDATION SYSTEM
===============================================================================

The BSP Generator now uses:

1. PYDANTIC MODELS (authoritative source)
   Location: modules/yaml/schemas.py
   Used by: All load_*_yaml() functions in modules/yaml/yaml_utils.py
   Benefits:
   - Runtime validation with detailed error messages
   - Type safety throughout codebase
   - Custom validation logic (duplicates, cross-refs, etc.)
   - Comprehensive unit tests (tests/test_yaml_schemas.py)

2. AUTO-GENERATED JSON SCHEMAS (for IDE support)
   Files: *.schema.json (in this directory)
   Generated by: scripts/generate_json_schemas.py
   Purpose:
   - IDE autocomplete and real-time validation
   - Documentation
   - External tooling

===============================================================================
MIGRATION NOTES
===============================================================================

If you need to modify a schema:
1. Edit the Pydantic models in modules/yaml/schemas.py
2. Run: python scripts/generate_json_schemas.py
3. The *.schema.json files will be regenerated automatically

DO NOT EDIT:
- *.schema.yaml (deprecated, not used)
- *.schema.json (auto-generated, will be overwritten)
