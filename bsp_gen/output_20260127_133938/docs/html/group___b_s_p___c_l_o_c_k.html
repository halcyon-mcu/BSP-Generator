enum clock_ref_t

Clock reference identifier.

Each peripheral clock reference is assigned a stable enum value. Peripheral drivers use these identifiers to enable clocks and query frequencies.

Enumerator

◆ clock_enable()

int clock_enable ( clock_ref_t ref)

Enable a peripheral clock.

Clears the disable bits for required clock sources and domains.

Enables the clock source and domain required for the given clock reference. This function is idempotent and will not disable clocks.

Note
Must be called before using the peripheral associated with the clock reference.
This function only enables clocks; it does not modify dividers or source selections.
Parameters
[in]refClock reference identifier
Returns
0 on success, -1 on invalid reference

Set the divider for a peripheral clock (APPLICATION-ONLY).

Warning
APPLICATION-ONLY: Do not call from peripheral drivers.
APPLICATION-ONLY: Do not call from peripheral drivers.
This function is intended for application code (e.g., main.c) to configure clock dividers before enabling peripherals.

Configures the clock divider for the specified clock reference. Only VCLK and VCLK2 are currently supported.

Note
The divider value is the actual divisor (1..16), not a register encoding.
After calling this function, clock_get_hz() will return the updated frequency.
Parameters
[in]refClock reference identifier
[in]dividerDivider value (1..16)
Returns
0 on success, -1 on invalid reference or divider
