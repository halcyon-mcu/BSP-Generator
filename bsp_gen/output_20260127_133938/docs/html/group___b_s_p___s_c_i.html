Detailed Description

Low-level driver for the RM46 SCI/LIN module.

This module provides:

  • SCI (UART) and LIN protocol support
  • Blocking transmit and receive APIs with timeout
  • Interrupt registration for level 0 and level 1 interrupts
  • Baud rate configuration
  • Loopback / self-test support

◆ sci_configure_baud()

void sci_configure_baud ( uint32_t baud_rate)

Configure the SCI baud rate.

Computes and sets the baud rate divisor from the current VCLK frequency. Assumes SCI module is out of reset and SWnRST bit is clear during configuration.

Parameters
[in]baud_rateDesired baud rate in bits per second
Note
Must be called after sci_init() and before enabling transmit/receive.
Warning
Re-enters reset during configuration (clears SWnRST), then restores it.

◆ sci_init()

void sci_init ( void )

Initialize the SCI module.

Enables the VCLK clock, brings the SCI out of reset, configures pin functions, and enables transmit and receive. This function must be called before any other SCI operations.

Note
This function does NOT configure baud rate or frame format. Use sci_configure_baud() and sci_configure_frame() after initialization.

◆ sci_receive_byte()

int sci_receive_byte ( uint8_t * data,
uint32_t timeout_cycles )

Receive a single byte (blocking with timeout).

Polls the RXRDY flag until a byte is ready, then reads it from the receive buffer. Checks and clears any error flags (framing, overrun, parity).

Parameters
[out]dataPointer to store received byte
[in]timeout_cyclesMaximum polling iterations before timeout
Returns
SCI_ERR_NONE on success, or bitwise OR of error flags (SCI_ERR_FRAMING, etc.)
Note
Blocking call. Not IRQ-safe.

◆ sci_self_test()

int sci_self_test ( void )

Run a simple loopback self-test.

Enables internal digital loopback, transmits a test byte, receives it, and verifies the result. Restores the original loopback state.

Returns
0 on success, non-zero on mismatch or timeout
Note
Module must be initialized and configured before calling.
Warning
This function temporarily places the module in reset.

◆ sci_transmit_byte()

int sci_transmit_byte ( uint8_t data,
uint32_t timeout_cycles )

Transmit a single byte (blocking with timeout).

Waits for the transmit buffer (TXRDY flag) to become ready, writes the byte, then waits for the transmitter to become empty (TX_EMPTY flag).

Parameters
[in]dataByte to transmit
[in]timeout_cyclesMaximum polling iterations before timeout
Returns
0 on success, SCI_ERR_TIMEOUT if transmit buffer or empty flag times out
Note
Blocking call. Not IRQ-safe.
