Detailed Description

SCI/LIN peripheral driver for TI RM46 (Cortex-R4).

This driver provides blocking transmit/receive, interrupt support, baud rate configuration, and loopback/self-test functionality for the SCI/LIN module.

Note
sci_init() must be called before any other SCI API. It will enable the VCLK clock reference, bring the module out of reset, and configure the pins and enables.
