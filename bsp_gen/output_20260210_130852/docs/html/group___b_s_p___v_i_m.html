Detailed Description

VIM driver for system-level interrupt handling on RM46 Cortex-R4.

The VIM provides vectored interrupt dispatch for up to 128 channels. Channel 0 is usable but phantom entry occupies table slot 0. Channels 1..126 are available; channel 127 is reserved.

◆ vim_init()

void vim_init ( void )

Initialize the VIM for vectored interrupts.

This function enables parity checking (if available), initializes all vector table entries to a default handler, and prepares the VIM for interrupt registration. No channels are enabled by default.

Warning
Must be called before registering or enabling any interrupts.
Note
This function does NOT enable any specific interrupt channels.

Register an ISR for a given VIM channel.

Stores the ISR address into the VIM vector table entry for the specified channel. The ISR will be invoked when the channel is both enabled and asserted.
