Detailed Description

SCI peripheral driver implementation.

Complete implementation of the Serial Communication Interface (SCI) driver including initialization, configuration, transmit/receive operations, int_type handling, and DMA support. Implements UART functionality with configurable baud rate, parity, data bits, and stop bits.
