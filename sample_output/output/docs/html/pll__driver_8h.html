Detailed Description

Public API for PLL peripheral driver.

Complete public interface for the PLL module including types, enumerations, structures, and function prototypes. This driver manages PLL configuration, clock domain control, and frequency reporting for all system clocks.

◆ PLL_Init()

void PLL_Init ( void )

Initialize the PLL and clock system with default configuration.

Configures PLL1, clock sources, dividers, and enables all clock domains according to SOC YAML configuration. Implements the complete initialization sequence.

Initialize the PLL and clock system with default configuration.

Implements the complete RM46 HAL-aligned initialization sequence:

  1. Disable PLL1/PLL2 sources and acknowledge
  2. Clear GLBSTAT slip flags
  3. Program PLLCTL1/PLLCTL2/PLLCTL3 with proven literals
  4. Program source/domain disable snapshots
  5. Enable sources and poll CSVSTAT for validity
  6. Program CLKCNTL VCLK/VCLK2 dividers BEFORE GHVSRC switch
  7. Switch GHVSRC to PLL1 source
  8. Program RCLKSRC and VCLKASRC
  9. Program CLK2CNTRL for VCLK3/VCLK4 dividers
  10. Program VCLKACON1 for VCLKA3/VCLKA4
  11. Clear PLLDIV fields in PLLCTL1/PLLCTL3
  12. Enable peripheral clock enable (PENA)
